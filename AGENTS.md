# Bahts — mesin penulisan bahts (riset ilmiah berbahasa Arab)

Satu bahts = satu folder; yang ditulis cuma `naskah.txt`, sisanya (cek rujukan, Word, PDF) dikerjakan mesin. Bahan bahts jangan masuk `mesin/`; `kitab/` dipakai semua bahts.
Daftar perintah: `python mesin/bahts.py`. Daftar tanda naskah: `python mesin/bahts.py tanda`.

## Peta aturan lanjutan (baca penuh sesuai tahap)

Aturan lengkap dipecah ke berkas terpisah agar tidak terpotong batas baca agent; jangan menebak aturan yang belum dibaca:
- `dok/pengaturan-bahts.md` — pembaruan mesin, `sampul_saya.txt`, `@judul`/`@sampul`/`@templat`/`@format`/`@angka`/`@spasi`/`@catatan_kaki`/`@ayat_pembuka`/`@maudhuat_letak`/`@tanpa: anzhur`/`@tahun`, diagram `#G`, rumus `#E`/`{E:}`, bahts bertahap `--fasl`, jumlah halaman, `PERINGATAN` sesudah `rakit`, dan `scan`.
- `dok/riset-alat.md` — urutan pilih alat, cadangan `shamela` → `qurangallery` → `turath`, 4 langkah wajib `riset.txt`, Waqfeya (`ambil w…`), aturan «Konteks = bab», dan tabel lengkap alat mesin & connector.
- `dok/pemeriksaan.md` — penanganan `GAGAL` dan `perhatian` (`--jejak`, `shamela_verify_quote`, `terima <kode> <alasan>`), prosedur penuh pemeriksa langkah 5 (Fokus A Isi & Sumber + Fokus B Tata Letak Visual), dan batas `cek`.
- `dok/penulisan-sumber.md` — standar sumber tertinggi (أبو سليمان), aturan takhrij & derajat hadits, bentuk rujukan pertama/ringkas, khilaf, 7 cara menukil & batas ±60 kata, dan الدراسات السابقة (`dirasat`/`dirasat-pdf`).
- `dok/mengubah-mesin.md` — aturan mengubah `mesin/`, `.github/`, README, atau `AGENTS.md`.

## Pemakai baru

Anggap pemakai baru pertama kali memakai agent, tidak membaca README, dan hanya memberi tautan repo plus permintaan bahts. Kerjakan semuanya sendiri; pemakai cukup menjawab pertanyaan. Pakai bahasa awam.

1. Repo belum ada di komputer → cek dulu folder `mesin-bahts` di dalam folder Dokumen pemakai. Belum ada → unduh ke sana: `git clone`, atau kalau `git` tidak ada, unduh `https://github.com/Farisarditiyanto/mesin-bahts/archive/refs/heads/main.zip` lalu ekstrak dan namai foldernya `mesin-bahts` (zip itu terekstrak sebagai `mesin-bahts-main`). Folder Dokumen = folder dokumen akun pemakai (di Windows bisa berada di dalam OneDrive). Jangan mengunduh ke folder sistem, folder program, atau folder kerja orang lain. Semua bahts pemakai tinggal di dalam folder itu.
2. Jalankan `python mesin/bahts.py periksa` (di Linux/macOS biasanya `python3`). Bereskan sendiri tiap baris `BELUM` dengan perintah yang disebutnya, lalu ulangi sampai tidak ada lagi yang bisa kamu bereskan. Baris huruf bertulisan «(hanya untuk @format …)» dilewati, kecuali naskah memakai profil itu: baris itu tidak menahan `rakit`, dan perintahnya memunculkan jendela izin admin. `python` tidak dikenal → pasang Python 3.12 dulu (Windows: `winget install Python.Python.3.12`); kalau sesudah itu `python` masih tidak dikenal di terminalmu, pakai `py`. Beri tahu pemakai bahwa `siapkan` memasang satu font (font mushaf) untuk akunnya.
3. `periksa` bilang `rakit` BELUM karena Windows atau Microsoft Word → beri tahu pemakai sekarang, sebelum menulis apa pun: hasilnya berhenti di naskah yang sudah dicek, tanpa Word dan PDF. Tanya: lanjut, atau pasang Word dulu. Jangan memasang Word sendiri dan jangan memakai pengganti Word. Yang BELUM «huruf Traditional Arabic» → jalankan perintah PowerShell admin yang disebut `periksa`, dan beri tahu pemakai dulu bahwa Windows akan menampilkan satu jendela izin: cukup klik Yes. Perintah itu selesai sesudah jendelanya menutup; ulangi `periksa`. Masih BELUM → minta pemakai menambah papan ketik Arab seperti yang disebut `periksa`.
4. Connector `shamela` wajib: jangan mengumpulkan bahan sebelum alat `shamela_*` tersedia. Sebelum menyimpulkan alatnya tidak ada, cari dulu dengan pencari alat agentmu (Claude Code: ToolSearch «shamela»): di banyak agent alat connector disembunyikan sampai dicari, dan lewat gateway MCP namanya berawalan lain (mis. `toolport__shamela__shamela_search_phrase`), barangnya sama. Tanda `shamela` tersambung = ada `shamela_search_phrase`; yang ada hanya `shamela_search` dan `shamela_find` = itu connector `qurangallery` (langkah 5), bukan `shamela`. Alat `shamela_*` tetap tidak ada → beri tahu pemakai: connector ini wajib, gunanya (mencari kitab yang membahas suatu masalah, termasuk yang belum diunduh) dan caranya: masuk dengan akun shamela.link sendiri sesudah connector-nya dinyalakan. Daftar connector dibaca sendiri oleh Claude Code dan Command Code (dari `.mcp.json`) serta OpenCode (dari `opencode.json`). Masuk akunnya: Claude Code `/mcp`; OpenCode `opencode mcp auth shamela`. Command Code: pendaftaran login otomatisnya ditolak shamela.link, jadi entri `shamela` di `.mcp.json` ditimpa entri lokal (di `~/.commandcode`, di luar repo: tanya pemakai dulu) yang membawa `clientId` repo. Beri tahu pemakai bahwa browser akan terbuka untuk masuk shamela.link. Dari folder repo, lewat bash atau PowerShell 7 (`pwsh`; PowerShell 5.1 membuang tanda kutip di dalam JSON), jalankan `commandcode mcp add-json --scope local shamela '{"type":"http","url":"https://shamela.link/mcp","oauth":{"clientId":"XibdiamYnAOtrCxycxRltQsDFisFhAWc","authorizationUrl":"https://shamela.link/api/auth/oauth2/authorize","tokenUrl":"https://shamela.link/api/auth/oauth2/token","scopes":["openid","offline_access"],"resource":"https://shamela.link/mcp","callbackPort":8085}}'` (di Git Bash, `cmd` = `cmd.exe` Windows: pakai `commandcode`). Perintah itu membuka login kalau belum ada token. `commandcode mcp list` harus menulis `shamela … local ✔`; belum ✔ → `commandcode mcp auth shamela`. Sesudah itu mulai sesi baru. Agent lain tidak membaca kedua berkas itu: daftarkan alamat dari `.mcp.json` lewat pengaturan MCP agent tersebut (Codex: `codex mcp add shamela --url https://shamela.link/mcp`, lalu `codex mcp login shamela`; Hermes: `hermes mcp add shamela --url https://shamela.link/mcp --auth oauth`, tautan masuknya muncul saat pertama tersambung). Connector tanpa akun didaftarkan dengan cara yang sama, tanpa langkah masuk. Itu mengubah pengaturan agent pemakai di luar repo: tanya dulu. Pemakai menolak atau belum bisa masuk → jangan mulai mengumpulkan bahan; jelaskan sebabnya dan tunggu sampai `shamela` tersambung.
5. Connector tanpa akun di `.mcp.json` ikut dipasang bersama `shamela`, supaya semuanya siap walau tidak semua dipakai: `qurangallery` (seluruh Shamela dengan nomor kitab yang sama: frasa persis, pencari sumber kutipan, juz/halaman cetak → `page_id`; cadangan pertama `shamela`), `turath` (isi semua kitab), `hadithunlocked` (hadits, derajat, syarah, sejarah), `tafsir` (tafsir per ayat, sebab turun, qiraat, i'rab), `quran` (teks ayat, morfologi, sebaran kata). Semuanya penunjuk jalan. Minta izinnya sekali untuk semua connector, jangan satu per satu. Bedanya dengan `shamela`: yang ini tidak menahan pekerjaan. Layanannya mati atau gagal tersambung → lanjut, lalu sebut di laporan akhir. Pemakai menolak → lewati.
6. Kunci OpenAlex wajib hanya untuk bahts yang memuat الدراسات السابقة; bahts lain tidak memerlukannya, jadi jangan dimintakan di awal. Dosen minta الدراسات السابقة, `kunci_openalex.txt` belum ada, dan variabel lingkungan `OPENALEX_API_KEY` kosong → minta kunci gratis (openalex.org > Settings > API key) sebelum menulis `#S`: tanpa kunci `dirasat-pdf` hanya bisa memakai tautan PDF akses terbuka, jadi isi banyak penelitian tidak bisa dibaca. Pemakai memberi kuncinya → simpan sebagai satu baris di berkas itu. Jangan menulis kunci itu di tempat lain.

## Sebelum tiap bahts

Baca penuh `dok/pengaturan-bahts.md` sebelum memulai bahts baru. Inti wajib yang selalu berlaku:
- Perbarui mesin hanya sebelum mulai bahts baru (`git pull --ff-only` bila `git status --porcelain` kosong), jangan di tengah pengerjaan bahts.
- Cek `sampul_saya.txt` (atau bahts terakhir untuk `bahts/<orang>/<topik>`), tanyakan pembimbing (`@musyrif`, `@jabatan`) tiap bahts, dan beri tahu bahwa sampul bawaan memakai kop جامعة الإمام dan قسم الشريعة.
- `@judul` harus sama persis dengan judul dari dosen, خطة, atau pemakai; jangan mengarang judul atau menambah sub-judul sampul (` - …`) sendiri.
- Jumlah halaman yang disebut pemakai = halaman isi (`HALAMAN_ISI`, المقدمة sampai الخاتمة); seluruh PDF < 25 halaman = perhatian `cek` dan PERINGATAN `rakit` (`@minimal_halaman`).
- Semua opsi tata letak (`@format`, `@templat`, `@sampul`, `@angka`, `@spasi`, `@catatan_kaki`, `@ayat_pembuka`, `@maudhuat_letak`, `@tanpa: anzhur`, `@tahun`, `@model: jakarta`, `--fasl`, `{N:}`, `{M:}`, `{X}`, `#G`, `#E`/`{E:}`, `#J`, `#V`, draf Word mahasiswa) dirinci di `dok/pengaturan-bahts.md`.
- Sebelum lapor selesai ke pemakai, `tahap <folder>` harus mencetak `NASKAH=LOLOS` dan `TERKINI`, lalu tulis letak lengkap PDF-nya.

## Alur kerja

Sesi baru, atau tidak tahu bahts ini sampai mana → `tahap <folder>` dulu, jangan menebak dari berkas di folder: ia membaca ulang naskah (`NASKAH=` GAGAL/PERHATIAN/LOLOS), hasil rakit (`HASIL=` BELUM/TERKINI/USANG/TIDAK_DIKETAHUI, juga tiap `--fasl`), rakit yang sedang jalan (`RAKIT=`), folder `.rakit-*`, dan cadangan `_arsip/rakit-*`, lalu mencetak satu `BERIKUTNYA`. Baris `PERLU PEMAKAI` → sebut ke pemakai, jangan dihapus sendiri.

1. `baru`, lalu susun خطة (فصل/مبحث/مطلب) sesuai permintaan dosen. خطة dosen menyebut isi المقدمة (mis. تساؤلات الدراسة) → sub-judul المقدمة ikut itu. Pisahkan peran المقدمة (konteks makro & kesenjangan masalah) dari الدراسات السابقة (pengelompokan tematik, celah kritis, dan jembatan ke bahts ini — bukan sekadar ringkasan berurutan). Jangan memecah bagian jadi satu sub-bagian tunggal (`#B` sendirian di bawah `#F`, atau `#M` sendirian di bawah `#B`: `cek` memberi perhatian `sub-bagian tunggal`). Sebelum mengumpulkan bahan, catat dalam rencanamu dua lapis sumber: **P0 (wajib)** — kitab mu'tamad tiap mazhab, nash pokok, standar resmi (mis. AAOIFI/IFRS), metode/indikator/dataset inti yang dibahas — dan **P1 (pendukung)** — konteks umum.

2. Kumpulkan bahan; kutip hanya dari teks yang benar-benar terbaca di sumber lokal (kitab lokal atau PDF yang diunduh), jangan dari ingatan pelatihan. **Wajib baca `dok/riset-alat.md` sebelum riset** untuk urutan alat (`mesin` offline → `shamela` → cadangan `qurangallery`/`turath`/`temukan` → `waqfeya` → `dirasat`/`dirasat-pdf`), aturan «Konteks = bab», batas & jebakan connector, dan tabel lengkap alat.
   Catat 4 langkah wajib di `riset.txt` begitu dijalankan (yang belum tercatat jadi perhatian `cek`; kalau layanan mati/kuota habis tulis `belum <langkah> <objek> <alasan>`):
   - Tiap hadits `{H:}` → `shamela_search_phrase` kategori 8 → `takhrij8 <kunci>`.
   - Tiap ayat `{Q:}` → baca tafsirnya → `tafsir <surat:ayat>`.
   - Tiap masalah khilaf → `shamela_research_scope` → `khilaf <istilah>`.
   - Tiap مبحث → `shamela_search_phrase` istilah kuncinya sebelum menulis → `cari <istilah> | <catatan>`.
3. Tulis `naskah.txt` dengan alat sunting agentmu (Edit/Write), bukan skrip Python buatan sendiri: skrip seperti itu sering rusak di konsol Windows (UnicodeEncodeError). `bahts.py` sudah mencetak UTF-8 sendiri; `PYTHONIOENCODING` tidak perlu. Setiap kutipan/penisbatan diberi catatan kaki berisi bukti `<<...>>`, termasuk nukilan makna tanpa tanda petik («انظر:»): kalimat yang menyebut pendapat mazhab, ulama, «الأصوليون»، «الجمهور»، ijmak, dalil, atau ta'lil dari kitab. Paragraf tanpa catatan kaki hanya untuk analisis penulis sendiri (الترجيح، النتيجة، pengantar bab), dan sebaiknya ditandai («ويظهر للباحث…»). `cek` tidak melihat kalimat tanpa catatan kaki; pemeriksa langkah 5 yang menilainya. Contoh yang lolos cek: `contoh/naskah.txt`.
4. `cek` sampai `GAGAL: 0`, tangani tiap baris `perhatian` (bereskan di naskah, atau `terima <kode> <alasan>` konkret ≥3 kata di `riset.txt` hanya bila tidak bisa dibereskan/salah tangkap; perhatian `riset.txt` tidak bisa diterima), lalu `rakit`. Prosedur lanjutan (`cek --jejak`, `shamela_verify_quote`, aturan `terima`) dan batas `cek` ada di `dok/pemeriksaan.md`.
5. Sebelum lapor selesai: minta subagent baru (yang tidak ikut menulis) menjalankan pemeriksaan penuh dua fokus — **(A) Isi & Sumber** (lewat `bukti <folder>`, cek kitab asal, konteks bab, paragraf tanpa catatan kaki, nukilan makna, `terima`, `riset.txt`, `@judul`) dan **(B) Tata Letak Visual** (lewat `pratinjau <folder>`) — lalu perbaiki temuan dan `cek` + `rakit` ulang. **Pemeriksa wajib membaca `dok/pemeriksaan.md` dan `dok/penulisan-sumber.md` seluruhnya sebelum menilai.**

## Standar sumber (selalu yang tertinggi)

Selalu pakai sumber asli tertua (أبو سليمان، كتابة البحث العلمي): pendapat mazhab dari kitab mu'tamad mazhabnya (`dok/mutamad.md`), ijmak/jumhur dari penukil tertuanya, ucapan ulama dari kitabnya sendiri, hadits dari kitab asal + derajat dari muhaddits, tafsir dari kitab tafsir, makna kata dari معاجم اللغة, masalah kontemporer dari keputusan المجامع/هيئة asli atau penelitian. Perantara hanya bila asalnya tidak bisa didapat dan ditandai «مقتبس من …» / «نقلا عن …». Rincian lengkap dan tabel aturan `cek`: baca `dok/penulisan-sumber.md`.

## Aturan penulisan

Dilarang mengarang nomor halaman, lafaz, penisbatan pendapat, atau derajat hadits: semua wajib terbaca di sumber lokal (Waqfeya: dari scan, bukan OCR). Ayat selalu `{Q:…}`; takhrij di luar Shahihain wajib berderajat yang terbaca di bukti; rujukan pertama kitab non-hadits memuat data cetak lengkap dari `kartu` tanpa gelar; kutipan utuh dibatasi ±60 kata di luar nash pokok; nukilan makna diawali `انظر:` dan setia pada asalnya. **Wajib baca `dok/penulisan-sumber.md` sebelum menulis `naskah.txt`** untuk rincian takhrij, khilaf, 7 cara menukil, dan الدراسات السابقة.

## Yang perlu diketahui

- Bentuk halaman dan huruf dikunci mesin menurut pedoman Jāmiʿat al-Imām («القواعد المنظمة لتسجيل الرسالة العلمية وكتابتها وطباعتها وتقديمها»، 1442هـ). Dosen minta lain → beri tahu pemakai: profil baru di `mesin/format.json` adalah perubahan mesin (bagian «Untuk yang mengubah mesin»), bukan pekerjaan bahts. Di folder pemakai jangan mengubah berkas `mesin/`: `git status` jadi tidak kosong, lalu pembaruan mesin berhenti (Sebelum tiap bahts, langkah 2). Jangan ubah `imam` (= isi pedoman dan bawaan). Yang berbeda hanya nomor catatan kaki atau spasi matan → `@catatan_kaki`/`@spasi` (di atas), bukan profil baru. Bahts baru memakai `imam_ayat16` (lewat `mesin/naskah_baru.txt`): sama dengan `imam`, ayat 16 supaya tidak tampak lebih besar daripada matan; naskah tanpa `@format` tetap `imam`.
- Sampul bawaan = `mesin/sampul_qism.docx`; `@sampul: mahad` = `mesin/sampul.doc`, sampul معهد العلوم الإسلامية والعربية في جاكرتا (teks penandanya diganti `rakit.ps1`; huruf judul dibaca dari paragraf «عنوان البحث» di templat). Pembimbing tercetak hanya kalau `@musyrif` diisi; `@jabatan` kosong = baris jabatan tidak tercetak.
- `PERINGATAN` sesudah `rakit` (sampul, nomor halaman, halaman sisa/kosong, teks/rumus meluap, baris akhir «:») dan pemeriksaan teks kitab lewat `scan` → lihat `dok/pengaturan-bahts.md`.
- `rakit` butuh Windows + Microsoft Word. `rakit` satu-satu (memakai Word yang sama); yang terlanjur dijalankan bersamaan antre sendiri sampai 30 menit, jadi jalankan di latar, bukan dengan batas waktu alat yang lebih pendek. Pesan antre menyebut rakit yang sedang jalan (folder, proses, jam mulai). Jangan mematikan Word, PowerShell, atau Python rakit, dan jangan menghapus atau memindahkan folder `.rakit-*`: rakit yang dimatikan gagal tanpa hasil, dan sisanya (Word, `.rakit-*`) dibereskan sendiri oleh `rakit` berikutnya. Folder `.rakit-*` bukan tanda rakit sedang jalan; yang benar `tahap <folder>` (`RAKIT=JALAN` beserta folder, proses, dan jam mulainya). `rakit` menyebut «Folder .rakit-… dibiarkan» (tanpa penanda bahan sementara; mis. berisi `JANGAN_DIHAPUS.txt` = hasil baru yang belum terpasang, atau disimpan versi lama) → lapor ke pemakai, jangan dihapus sendiri.
- Yang dibaca dan dikumpulkan = PDF. `.docx` hanya untuk Word (di Google Docs tampilannya pasti beda). Perubahan isi selalu lewat `naskah.txt`, bukan lewat .docx.

## Untuk yang mengubah mesin
Mengubah apa pun di `mesin/`, `.github/`, README, atau berkas ini → baca dulu `dok/mengubah-mesin.md` (tes, CHANGELOG, letak kode, salinan terpaksa).
