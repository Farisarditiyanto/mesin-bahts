# Pemakai baru

Lanjutan `AGENTS.md` bagian «Pemakai baru». Baca penuh saat pemakai baru pertama kali memakai agent atau belum menyelesaikan pemasangan awal (`periksa`, connector `shamela`, kunci OpenAlex).

Anggap pemakai baru pertama kali memakai agent, tidak membaca README, dan hanya memberi tautan repo plus permintaan bahts. Kerjakan semuanya sendiri; pemakai cukup menjawab pertanyaan. Pakai bahasa awam.

1. Repo belum ada di komputer → cek dulu folder `mesin-bahts` di dalam folder Dokumen pemakai. Belum ada → unduh ke sana: `git clone`, atau kalau `git` tidak ada, unduh `https://github.com/Farisarditiyanto/mesin-bahts/archive/refs/heads/main.zip` lalu ekstrak dan namai foldernya `mesin-bahts` (zip itu terekstrak sebagai `mesin-bahts-main`). Folder Dokumen = folder dokumen akun pemakai (di Windows bisa berada di dalam OneDrive). Jangan mengunduh ke folder sistem, folder program, atau folder kerja orang lain. Semua bahts pemakai tinggal di dalam folder itu.
2. Jalankan `python mesin/bahts.py periksa` (di Linux/macOS biasanya `python3`). Bereskan sendiri tiap baris `BELUM` dengan perintah yang disebutnya, lalu ulangi sampai tidak ada lagi yang bisa kamu bereskan. Baris huruf bertulisan «(hanya untuk @format …)» dilewati, kecuali naskah memakai profil itu: baris itu tidak menahan `rakit`, dan perintahnya memunculkan jendela izin admin. `python` tidak dikenal → pasang Python 3.12 dulu (Windows: `winget install Python.Python.3.12`); kalau sesudah itu `python` masih tidak dikenal di terminalmu, pakai `py`. Beri tahu pemakai bahwa `siapkan` memasang satu font (font mushaf) untuk akunnya.
3. `periksa` bilang `rakit` BELUM karena Windows atau Microsoft Word → beri tahu pemakai sekarang, sebelum menulis apa pun: hasilnya berhenti di naskah yang sudah dicek, tanpa Word dan PDF. Tanya: lanjut, atau pasang Word dulu. Jangan memasang Word sendiri dan jangan memakai pengganti Word. Yang BELUM «huruf Traditional Arabic» → jalankan perintah PowerShell admin yang disebut `periksa`, dan beri tahu pemakai dulu bahwa Windows akan menampilkan satu jendela izin: cukup klik Yes. Perintah itu selesai sesudah jendelanya menutup; ulangi `periksa`. Masih BELUM → minta pemakai menambah papan ketik Arab seperti yang disebut `periksa`.
4. Connector `shamela` wajib: jangan mengumpulkan bahan sebelum alat `shamela_*` tersedia. Sebelum menyimpulkan alatnya tidak ada, cari dulu dengan pencari alat agentmu (Claude Code: ToolSearch «shamela»): di banyak agent alat connector disembunyikan sampai dicari, dan lewat gateway MCP namanya berawalan lain (mis. `toolport__shamela__shamela_search_phrase`), barangnya sama. Tanda `shamela` tersambung = ada `shamela_search_phrase`; yang ada hanya `shamela_search` dan `shamela_find` = itu connector `qurangallery` (langkah 5), bukan `shamela`. Alat `shamela_*` tetap tidak ada → beri tahu pemakai: connector ini wajib, gunanya (mencari kitab yang membahas suatu masalah, termasuk yang belum diunduh) dan caranya: masuk dengan akun shamela.link sendiri sesudah connector-nya dinyalakan. Daftar connector dibaca sendiri oleh Claude Code dan Command Code (dari `.mcp.json`) serta OpenCode (dari `opencode.json`). Masuk akunnya: Claude Code `/mcp`; OpenCode `opencode mcp auth shamela`. Command Code: pendaftaran login otomatisnya ditolak shamela.link, jadi entri `shamela` di `.mcp.json` ditimpa entri lokal (di `~/.commandcode`, di luar repo: tanya pemakai dulu) yang membawa `clientId` repo. Beri tahu pemakai bahwa browser akan terbuka untuk masuk shamela.link. Dari folder repo, lewat bash atau PowerShell 7 (`pwsh`; PowerShell 5.1 membuang tanda kutip di dalam JSON), jalankan `commandcode mcp add-json --scope local shamela '{"type":"http","url":"https://shamela.link/mcp","oauth":{"clientId":"XibdiamYnAOtrCxycxRltQsDFisFhAWc","authorizationUrl":"https://shamela.link/api/auth/oauth2/authorize","tokenUrl":"https://shamela.link/api/auth/oauth2/token","scopes":["openid","offline_access"],"resource":"https://shamela.link/mcp","callbackPort":8085}}'` (di Git Bash, `cmd` = `cmd.exe` Windows: pakai `commandcode`). Perintah itu membuka login kalau belum ada token. `commandcode mcp list` harus menulis `shamela … local ✔`; belum ✔ → `commandcode mcp auth shamela`. Sesudah itu mulai sesi baru. Agent lain tidak membaca kedua berkas itu: daftarkan alamat dari `.mcp.json` lewat pengaturan MCP agent tersebut (Codex: `codex mcp add shamela --url https://shamela.link/mcp`, lalu `codex mcp login shamela`; Hermes: `hermes mcp add shamela --url https://shamela.link/mcp --auth oauth`, tautan masuknya muncul saat pertama tersambung). Connector tanpa akun didaftarkan dengan cara yang sama, tanpa langkah masuk. Itu mengubah pengaturan agent pemakai di luar repo: tanya dulu. Pemakai menolak atau belum bisa masuk → jangan mulai mengumpulkan bahan; jelaskan sebabnya dan tunggu sampai `shamela` tersambung.
5. Connector tanpa akun di `.mcp.json` ikut dipasang bersama `shamela`, supaya semuanya siap walau tidak semua dipakai: `qurangallery` (seluruh Shamela dengan nomor kitab yang sama: frasa persis, pencari sumber kutipan, juz/halaman cetak → `page_id`; cadangan pertama `shamela`), `turath` (isi semua kitab), `hadithunlocked` (hadits, derajat, syarah, sejarah), `tafsir` (tafsir per ayat, sebab turun, qiraat, i'rab), `quran` (teks ayat, morfologi, sebaran kata). Satu connector di daftar yang sama perlu akun: `qaf` (pencari nash menurut makna, Arab atau Inggris) ikut dipasang, tetapi perlu masuk akun Qaf gratis (qaf.ai) seperti `shamela`: Claude Code `/mcp`, OpenCode `opencode mcp auth qaf`, Codex `codex mcp add qaf --url https://api.qaf.ai/mcp` lalu `codex mcp login qaf`; belum punya akun atau tidak mau → lewati. Semuanya penunjuk jalan. Minta izinnya sekali untuk semua connector, jangan satu per satu. Bedanya dengan `shamela`: yang ini tidak menahan pekerjaan. Layanannya mati atau gagal tersambung → lanjut, lalu sebut di laporan akhir. Pemakai menolak → lewati.
6. Kunci OpenAlex wajib hanya untuk bahts yang memuat الدراسات السابقة; bahts lain tidak memerlukannya, jadi jangan dimintakan di awal. Dosen minta الدراسات السابقة, `kunci_openalex.txt` belum ada, dan variabel lingkungan `OPENALEX_API_KEY` kosong → minta kunci gratis (openalex.org > Settings > API key) sebelum menulis `#S`: tanpa kunci `dirasat-pdf` hanya bisa memakai tautan PDF akses terbuka, jadi isi banyak penelitian tidak bisa dibaca. Pemakai memberi kuncinya → simpan sebagai satu baris di berkas itu. Jangan menulis kunci itu di tempat lain.
